# 04. 必要書類・体制チェックリスト

医療機器プログラムに該当した場合（ルートB）に必要となるものの一覧。
非該当の場合は「広告レビュー」の節のみ使用。

## 業許可関係

- [ ] 医療機器製造販売業許可申請書（第一種/第二種）
- [ ] 三役の資格確認・選任（総括製造販売責任者／国内品質業務運営責任者／安全管理責任者）
- [ ] 医療機器製造業登録申請（設計拠点）
- [ ] 組織図・業務手順書一式（QMS省令・GVP省令対応）

## QMS・設計開発文書

- [ ] 品質マニュアル（ISO 13485 / QMS省令準拠）
- [ ] 製品要求仕様書・設計仕様書
- [ ] リスクマネジメントファイル（JIS T 14971）
- [ ] ソフトウェアライフサイクル文書（IEC 62304 / JIS T 81001-5-1 相当: 開発計画、アーキテクチャ、検証記録）
- [ ] サイバーセキュリティ対応文書（医療機器サイバーセキュリティ導入ガイダンス対応）
- [ ] ユーザビリティ/添付文書（電子化された添付文書: 注意事項等情報）

## 申請書類（認証/承認共通の骨子）

- [ ] 申請書（一般的名称・クラス分類・使用目的）
- [ ] STED（開発の経緯、使用目的、性能・安全性に関する資料の概要）
- [ ] 性能試験成績（アルゴリズム性能評価を含む）
- [ ] 臨床評価報告書（必要な場合）
- [ ] 製造方法・品質管理に関する資料

## 広告レビュー（該当・非該当を問わず）

- [ ] ストア掲載文（App Store / Google Play）の表現チェック
- [ ] LP・Webサイトの表現チェック
- [ ] 営業資料・プレスリリースの表現チェック
- [ ] レビュー担当者と承認フローの決定
