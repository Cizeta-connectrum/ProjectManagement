## 事例1: ENDEAVORRIDE（エンデバーライド）／ EndeavorRx

ゲーム形式のデジタル治療用アプリ（DTx）が日米両方で承認された代表事例。
**「ゲームであること」は医療機器該当性・承認取得の障害にならない**（＝逆に言えば、
治療効果を標榜するならゲームアプリでも本格的な医療機器承認が必要になる）ことを示す。

### 1-1. 日本での承認（塩野義製薬、2025年2月）

| 項目 | 内容 |
|---|---|
| 販売名 | ENDEAVORRIDE（エンデバーライド） |
| 申請者 | 塩野義製薬（Akili社から日本・台湾の独占的開発・販売権を導入） |
| 類別 / 一般的名称 | プ02 疾病治療用プログラム / **注意欠如多動症治療補助プログラム** |
| 承認番号 | 30700BZX00033 |
| 申請日 → 承認日 | 2024年2月26日 → **2025年2月13日（審査期間 約12か月）** |
| 審査 | PMDA プログラム医療機器審査部 → 医療機器・体外診断薬部会 プログラム医療機器調査会 |
| 使用目的 | 小児期におけるADHDの**治療補助**（対象: 混合型・不注意優勢型のみ） |
| 承認条件 | 関連学会作成の適正使用指針の周知、医師への講習等の措置 |
| 使用成績評価 | 対象指定なし |

**審査でのポイント（審査報告書より）**

- 使用目的は申請時の「ADHDの**治療**」から「ADHDの**治療補助**」へ審査中に修正された。
  臨床的位置づけ（環境調整・心理社会的治療で効果不十分な患者への追加選択肢）を
  反映した限定表現に落ち着いている
- **多動/衝動優勢型はデータがないため適応から除外**。エビデンスのある集団にのみ
  適応が認められる
- ゲーム型治療ゆえの固有リスクとして**電子機器依存（ゲーム依存）**が審査で問題になり、
  注意事項等情報での注意喚起＋学会の適正使用指針＋医師講習（承認条件）で管理する整理
- 非臨床資料: JIS T 2304（IEC 62304）準拠のソフトウェアライフサイクル
  （**安全クラスB**）、性能規格、JIS T 14971準拠リスクマネジメント、
  サイバーセキュリティガイダンス（平成30年薬生機審発0724第1号）対応
- **製造方法に関する資料は「医療機器プログラムの取扱いについて」（平成26年薬食機参発
  1121第33号）に基づき提出省略**（SaMDでは定番の扱い）
- 臨床資料: 国内2試験（検証的A3831・探索的A3821）＋米国3試験
  - A3831（6〜17歳、無作為化・非盲検・通常治療対照）: 主要評価項目
    ADHD-RS-IV（医師評価）不注意スコア変化量 本品群−4.44 vs 通常治療群−1.47
    （群間差−2.97、95%CI −4.38〜−1.56）で有意
  - 安全性: 重篤な機器関連有害事象なし。有害作用は軽度・回復

### 1-2. 米国での承認（Akili社 EndeavorRx、FDA De Novo、2020年6月）

| 項目 | 内容 |
|---|---|
| 承認区分 | **De Novo**（新規機器分類の創設。DEN200026） |
| 分類 | Class II / 新設規制番号 21 CFR 882.5803 / プロダクトコード QFT |
| 機器タイプ | Digital therapy device for ADHD（臨床医の管理下の補助治療） |
| Indications | 8〜12歳の不注意優勢型/混合型ADHD児の**注意機能（TOVAで測定）の改善** |
| 販売制限 | **処方箋医療機器**（Rx only）。単独治療（stand-alone）としての使用は不可 |

**FDA審査でのポイント（De Novo Summary より）**

- エビデンス: 5臨床試験・計600人超。ピボタル試験STARS-ADHDは**348例の無作為化二重盲検
  デジタル対照試験**（対照は治療アルゴリズムを抜いた「偽ゲーム」＝digital control）。
  主要評価項目 TOVA API変化 0.93 vs 0.03（p=0.006）
- 効能の書き方が極めて限定的:「コンピュータ検査で測定される注意機能の改善」であり、
  多動などの行動症状の改善は謳えない（may not display benefits...と明記）
- ソフトウェアは「MODERATE level of concern」として審査
- リスクと緩和策が特別管理（Special Controls）として類型化: 無効治療・ソフト障害・
  フラストレーション/頭痛等・発作・**スクリーン依存**・睡眠の質低下 → 臨床性能試験＋
  ラベリング＋V&Vで緩和
- 有害事象はフラストレーション耐性低下（2.8%）、頭痛等いずれも軽微・一過性

### 1-3. PaTaKaRUSHへの示唆

1. **標榜内容がすべてを決める**: 「治療」「治療補助」「症状改善」を謳うなら、
   ゲームアプリでも検証的臨床試験（数百例規模・対照群付き）を含むフル承認パッケージが
   必要。塩野義ですら申請までに国内2試験・申請から承認まで1年を要した
2. **効能表現は審査で削られる前提**: エビデンスのある範囲（対象集団・測定指標）に
   限定される。逆に、限定的な効能（例: 特定の検査指標の改善）でも承認は取れる
3. **ゲーム型固有の論点**: ゲーム依存・スクリーンタイムのリスクは日米両当局が
   指摘。ゲーム性のあるヘルスケア/医療アプリでは必ず問われると想定すべき
4. **対照群の設計**: 「アルゴリズムを抜いた偽ゲーム」をデジタルプラセボとする
   試験デザインは、ゲーム型アプリの有効性証明のモデルケース
5. **非該当路線との対比**: 上記1のコスト・期間を踏まえると、PaTaKaRUSHが
   まず非該当（ウェルネス）として市場投入し、エビデンスを蓄積してから
   医療機器版を別途開発する二段構えも現実的な選択肢
6. **学会との連携**: 治療アプリでは適正使用指針の策定が承認条件になり得るため、
   医療機器路線を取るなら関連学会（口腔・嚥下領域なら日本老年歯科医学会、
   日本摂食嚥下リハビリテーション学会等）との早期の関係構築が重要
