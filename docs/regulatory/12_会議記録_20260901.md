# 12. 会議記録 — PaTaKaRUSH優先審査の検討（2026年9月1日）

> 出席: 西願、十河、辻野　／　原本: Google Docs（社内共有）
> 本ファイルは議事録の要点整理。決定事項は関連ファイル（10・11ほか）へ反映済み。

## 決定事項

1. **画期性の軸**: 検査・治療・予防の複数機能を包含する方向で申請を進める。
   ただし「予防」の有効性証明は長期エビデンスが必要で難易度が高いため、
   現状の表現は**「検査・治療（予防を含む）」**に留めるのが現実的
2. **要件1の訴求5本柱**（検査と治療〔予防を含む〕の一体的提供を軸に強調する点）:
   1. AI音声認識と言語モデルを活用した精緻な検査・トレーニング機能
   2. ゲームコンテンツ化による継続的な行動変容支援
      （※2026-09-12修正: 「行動変容」は通知なお書きの類型〔行動変容を促すプログラムに画期性なし〕を
      自称することになるため主張せず、「ゲーミフィケーションによる訓練の習慣化（継続）の支援」に変更）
   3. 遠隔地からの治療効果管理と、それによる医療アクセス向上
   4. 口腔筋群全体（口唇・舌・咀嚼筋等）の評価とトレーニングへの包括的アプローチ
   5. 将来的なビッグデータ解析による機能改善・エビデンス構築の可能性
3. **要件2**: これまでのユーザーデータを元に臨床的意義を訴求する
4. **販売名**: 医療機器版は**「PaTaKaRUSH Pro」**とし、一般製品と明確に区別する
5. **様式記載方針**: 「構造」「形状」「原理」「使用目的・効果」を明確に定義し、
   特に「原理」でAI画像認識技術を核とした革新性を記述する
6. **用語**: 既存承認事例の**「口腔機能発達不全症における口腔機能リハビリテーション」**
   という用語を参考に、適用範囲と目的を明確化する

## 共有された制約・リスク（再確認）

- 優先審査指定制度では二段階承認は適用できない（併用不可）
- 製品仕様は申請時に厳密に固定が必要。後からの機能追加・削除は困難
- 結果が出なかった場合の指定取消しリスク
- EndeavorRx等の適応型難易度制御は画期性の強力な参考だが、あくまで参考情報であり
  直接的な証明にはならない

## 保留・次回への持ち越し論点

1. **「予防」の定義とエビデンス**: どう定義し既存ガイドラインと整合させるか、
   「治療（予防を含む）」の表現に留めるか
2. **管理項目の詳細検討**: 舌口唇運動検査の既存7検査項目（プロセス系＝原因を見る／
   結果系＝結果を見る）とPaTaKaRUSH機能の対応、統合された管理方法。
   グミゼリー等のツールの位置づけ
3. **二段階承認とのトレードオフ再確認**: 「1段階で大きな承認」方針の背景にある
   トレードオフ（機能変更の柔軟性喪失等）のリスク・機会評価
4. **重点カテゴリの絞り込み**: 検査・治療・予防をすべて網羅すると訴求点が不明確に
   なる恐れ。各機能の画期性とエビデンス難易度を考慮した重点配分
5. **販売名とポジショニング**: 医療機器としての区別を示す名称・表記の調整、
   ブランドイメージ戦略（審査における誤解回避）
