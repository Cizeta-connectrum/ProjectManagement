| 資料/窓口 | 概要 |
|---|---|
| 厚労省「プログラムの医療機器該当性に関するガイドライン」 | 該当性判断の一次資料。事例集（該当/非該当の具体例）が特に有用 |

## 主要法令・規格

| 略称 | 正式名/内容 |
|---|---|
| 薬機法 | 医薬品、医療機器等の品質、有効性及び安全性の確保等に関する法律 |
| QMS省令 | 医療機器及び体外診断用医薬品の製造管理及び品質管理の基準に関する省令 |
| GVP省令 | 製造販売後安全管理の基準 |
| JIS T 14971 | 医療機器—リスクマネジメント |
| IEC 62304 / JIS T 81001-5-1 | 医療機器ソフトウェアのライフサイクルプロセス/セキュリティ |
| ISO 13485 | 医療機器の品質マネジメントシステム |

## 用語集

| 用語 | 意味 |
|---|---|
| SaMD | Software as a Medical Device。単体で医療機器となるプログラム |
| 該当性 | プログラムが薬機法上の「医療機器」に当たるかどうか |
| 一般的名称（JMDN） | 医療機器の分類名。クラス分類・認証基準の有無がこれで決まる |
| クラス分類 | リスクに応じたI〜IVの分類。プログラムは通常II以上 |
| 認証 | 認証基準のあるクラスII機器について第三者認証機関が行う審査 |
| 承認 | PMDAが審査し厚労大臣が与える。認証基準がない場合等 |
| 三役 | 総括製造販売責任者・品質保証責任者（国内品質業務運営責任者）・安全管理責任者 |
| STED | Summary of Technical Documentation。申請資料の様式 |
| 軽微変更/一部変更 | 承認・認証後の変更手続き区分。アプリ更新のたびに判断が必要 |
