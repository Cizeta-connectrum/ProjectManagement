# PaTaKaRUSH 薬事申請 情報集約ハブ

PaTaKaRUSHアプリの薬事申請（薬機法対応）に関する情報を、このディレクトリに集約します。
新しい情報（社内決定事項、PMDA・行政とのやり取り、参考資料など）が入手できたら、
該当ファイルに追記していってください。

## ディレクトリ構成

| [02_該当性判断.md](02_該当性判断.md) | 医療機器プログラム（SaMD）該当性の検討 | 検討フレームのみ記載 |

## 進め方（全体像）

1. **製品情報の確定**（01）: 使用目的・対象者・アプリの出力（表示・助言）を言語化する
2. **該当性判断**（02): 「医療機器プログラムに該当するか」を判断する。ここが最初の分岐点
   - 非該当（ヘルスケア・ウェルネスアプリ）→ 薬事申請不要。ただし広告表現の制限あり
   - 該当 → クラス分類を確定し、申請ルート（届出／認証／承認）へ
3. **申請準備**（03・04): 業許可（製造販売業・製造業登録）、QMS体制、申請書類の準備
4. **申請・審査対応**（05に記録を蓄積）

## 注意

- 本ディレクトリの一般論は作成時点の公開情報に基づく整理です。最終判断は必ず
  PMDA・厚生労働省・都道府県薬務主管課の最新の通知・相談結果に基づいて行ってください。
- 該当性がグレーな場合は、都道府県薬務課またはPMDAの「医療機器プログラム該当性相談」の
  利用を強く推奨します（判断の根拠を文書で残せます）。
