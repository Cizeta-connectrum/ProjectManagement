# 03. 申請ロードマップ（該当性判断後）

該当性判断（02）の結果に応じて、進むルートが分かれます。

## ルートA: 非該当（ヘルスケアアプリ）

薬事申請は不要。ただし以下を実施:

- [ ] 広告・ストア表現の薬機法/景表法レビュー体制を作る
- [ ] 該当性の判断根拠（相談記録・ガイドライン照合結果）を保管
- [ ] 将来のアップデートで判定機能等を追加する際の再判断プロセスを決める

## ルートB: 医療機器プログラムに該当する場合

### 1. クラス分類・一般的名称の確定

- 医療機器プログラムは通常 **クラスII以上**（クラスIのプログラムは原則医療機器から除外）
- 既存の**一般的名称**に当てはまるかを確認（JMDNコード）
  - 当てはまり、**認証基準がある** → 第三者認証機関による**認証**（クラスII）
  - 認証基準がない/新規性が高い → **PMDA承認申請**（クラスII承認 or クラスIII以上）

### 2. 業態の整備（申請と並行して必要）

| 許可・登録 | 申請先 | 備考 |
|---|---|---|
| 医療機器製造販売業許可（第二種: クラスII / 第一種: クラスIII以上） | 都道府県 | 三役（総括製造販売責任者・品質保証責任者・安全管理責任者）の設置が必要 |
| 医療機器製造業登録（設計） | 都道府県 | プログラムの場合は設計拠点の登録 |
| QMS体制（省令準拠） | — | ISO 13485ベースの品質マネジメントシステム構築 |

### 3. 申請〜上市までの標準ステップ

1. [ ] PMDA相談（開発前相談・該当性相談・申請前相談を段階的に活用）
2. [ ] 設計開発文書の整備（要求仕様、リスクマネジメント: JIS T 14971、ソフトウェアライフサイクル: JIS T 81001-5-1 / IEC 62304 相当）
3. [ ] 臨床評価（臨床試験が必要か、文献・性能試験で足りるかをPMDA相談で確定）
4. [ ] 認証申請 or 承認申請（STED様式の申請資料作成）
5. [ ] QMS適合性調査
6. [ ] 認証/承認取得 → 製造販売届出事項の整備 → 上市
7. [ ] 上市後: 不具合報告体制、変更管理（アプリのアップデートは軽微変更/一部変更の判断が毎回必要）
