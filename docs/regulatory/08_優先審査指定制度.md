# 08. プログラム医療機器等 優先審査指定制度への申請

> 根拠通知: 「プログラム医療機器等に係る優先的な審査等の試行的実施について」
> （令和8年6月15日 医薬機審発0615第1号、厚労省医薬局医療機器審査管理課長通知）
> 原本: `sources/優先審査等試行的実施通知_R08.06.15.pdf`
>
> **方針決定（2026-08-31）: まずこの制度への指定申請を目指す。**

## 制度の概要

革新的なプログラム医療機器（SaMD）を指定し、優先的な相談・審査等を試行的に実施する制度。
指定されると以下のメリットがある。

1. **優先相談**: PMDA対面助言等で他機器に優先した取扱い
2. **事前評価の充実**: 先駆け総合評価相談の活用により、**承認申請から承認までを
   全申請区分で6か月以内**に短縮（事前評価が不十分な場合は個別設定）
3. **優先審査**: 指定をもって法23条の2の5第10項の優先審査扱い
4. **コンシェルジュ**: PMDA指名の担当者が開発進捗管理・省庁間調整を支援
5. **革新的医療機器等相談承認申請支援事業**の対象（相談費用の支援）

### 対象外となるケース（注意）

- **リバランス通知**（平成29年薬生機審発1117第1号）や**二段階承認通知**
  （令和5年医薬機審発1116第2号）の活用を希望する品目は対象外
- 指定後にこれらの活用を相談した場合も**指定取消し**

## 指定の3要件（すべて充足が必要）

| 要件 | 内容 | PaTaKaRUSHでの評価（現時点の見立て） |
|---|---|---|
| **要件1: 画期性** | 原理が既存の医療機器・標準的治療法と明らかに異なり画期的であること。**「医療現場の患者指導と同様の内容を自宅で提供し行動変容を促すだけのプログラムは原則、画期性なし」と明記** | ⚠️ **最大の関門**。パタカラ訓練（口腔機能訓練）自体は医療・介護現場の標準的指導。単なる「訓練のゲーム化・宿題化」では画期性なしと判断されるリスクが高い。音声解析による**リアルタイム適応型の閉ループ訓練**（患者の発声能力に応じ難易度・刺激を自動最適化する独自アルゴリズム等）を「既存の訓練指導とは原理が異なる」と説明できるかが勝負 |
| **要件2: 医療上の有用性** | ア: 既存治療がない疾患で臨床試験等で有効性・安全性が見込まれる／イ: 既存治療より高い有効性・安全性／ウ: 同等以上＋患者負担軽減等で特に有用。**いずれも「臨床試験等において」見込まれることが前提**（公的競争的資金による臨床研究含む） | ⚠️ **臨床データが前提**。指定申請前に、少なくとも探索的な臨床試験・臨床研究（パイロットRCT等）で有効性を示唆するデータが必要。口腔機能低下症/発達不全症には既存の訓練指導があるため、イ（高い有効性）またはウ（同等以上＋負担軽減・アドヒアランス向上）での主張になる見込み |
| **要件3: 世界先駆け** | 世界に先駆けて又は同時（3か月以内）に日本で承認申請する意思・体制。先駆け総合評価相談を活用できる体制。**同様の原理の類似製品が世界で既に流通している場合は対象外** | ✅ 国産・日本先行開発なら主張しやすい。ただし海外の口腔機能訓練アプリ（医療機器として流通しているもの）の有無を調査し「類似製品が流通していない」ことを示す必要あり |

さらに「同等の原理に基づく使用目的・効果を有する他の医療機器が既に承認されている場合は
原則指定しない」→ 国内で口腔機能訓練用SaMDの承認が先行していないことの確認も必要。

## 指定の手続き（フロー）

1. **登録申込み**: 様式1（指定希望品目登録申込書＋別紙）を電子メールで
   `kikisaisei@mhlw.go.jp`（厚労省医療機器審査管理課）へ随時提出
2. **ヒアリング**: 医療機器審査管理課によるヒアリング。根拠資料は実施予定日の
   **1週間前まで**にメール提出
3. **予備的審査**: 明らかに要件非該当の品目を除外（結果は速やかに連絡）
4. **指定申請・評価**: 通過後、様式2＋根拠資料を期限までに提出 → PMDA評価 →
   分野ごとに「特に優れている」と判断された品目を選定 → 薬事審議会報告・公表

## 指定取消し事由（指定後の留意点)

- 要件のいずれかに該当しなくなった場合
- 指定後の試験で想定した高い有用性が見込まれないことが判明した場合
- **有効性・安全性に関わる大幅なプログラム変更**を行った/必要になった場合
  （→ 指定後はアプリの機能変更の自由度が下がる。申請までの機能凍結計画が必要）
- リバランス通知・二段階承認の活用を相談した場合

## PaTaKaRUSHの申請準備 ギャップ分析

登録申込み（様式1）までに揃えるべきもの:

- [ ] **画期性の説明資料**: 既存の口腔機能訓練指導・既存SaMDとの原理の違いを図解
      （適応型アルゴリズム・閉ループ設計等の独自性。特許出願状況も補強材料になる）
- [ ] **臨床データ**: 探索的臨床試験/臨床研究の計画・実施（AMED等の公的競争的資金の
      活用も選択肢。要件2は「臨床試験等において見込まれる」ことを求めるため、
      **データゼロでの指定は困難**）
- [ ] **類似品調査**: 国内承認品・世界で流通する類似SaMDの網羅的調査結果
- [ ] **開発体制の説明**: 先駆け総合評価相談を受けられる体制（薬事担当・QMS・
      開発計画）、日本先行申請のコミットメント
- [ ] 様式1・別紙の入手と記載（通知の別添様式を厚労省サイトから取得）

## 戦略上の論点（要意思決定）

1. **二段階承認との二者択一**: この指定を取ると二段階承認（第1段階=限定的な使用目的で
   早期承認→第2段階=本格承認）は使えない。エビデンス構築に時間がかかる場合、
   二段階承認の方が現実的な可能性もある。**両にらみで進め、探索的試験の結果を見て
   どちらのルートにコミットするか決めるのが安全**（ただし指定後の二段階相談は取消し事由）
2. **指定は承認ではない**: 指定されても承認申請パッケージ（03・04参照）は必要。
   指定の効果は「速く・手厚くなる」こと
3. **落選しても失うものは少ない**: 予備的審査で除外されても薬事手続き上の不利益はなく、
   ヒアリングで行政の感触を得られる。ただし要件1・2が弱いまま出すと説得力のある
   ストーリーを作ってから再挑戦する機会を1回消費する
